### A cloud agent keeps its cloud in plan mode

##### Fixed

- An agent that runs in the cloud shows its `☁` on PROJECTS, on a
  channel's MEMBERS and on its subagents' rows whatever it is doing.
  While it was in plan mode the `(P)` badge replaced the cloud, and since
  cloud members plan each task first, a working cloud member often
  showed no cloud at all. The row now reads `(P) ☁`.
